# Orbit wins on bundling, loses on plumbing

Orbit already matches the sprint core of every serious competitor: backlog, sprint start and complete with carry-over, story points, an epic/story/task/bug hierarchy, issue keys, subtasks, dependencies, burndown, velocity, workload reports, list, calendar and Gantt views, and Cmd-K search. It also ships things most rivals either lack or sell separately: ideas with voting and a mind map, whiteboards and flowcharts linked to issues, built-in time tracking with timesheets, and a fast desktop app. What it lacks is the connective layer that 2026 buyers now treat as table stakes. That layer is a public API and webhooks, an MCP server, AI assistance, GitHub integration, importers, custom fields and statuses, and the collaboration basics: mentions, watchers, email and Slack notifications, and saved filters. Every major tracker reviewed now ships an official hosted MCP server, and the fastest-growing capability in the category is "assign this issue to a coding agent and get a PR back." Without an API, Orbit cannot take part in that ecosystem at all. Its three planned items (real API keys, an MCP server, and a bring-your-own-key AI copilot) are the right first moves. BYOK in particular fills an open slot, because mainstream trackers all meter AI through credits or per-seat add-ons. The biggest risk is not missing features but the path to adding them: Jira's complaints are about complexity and Linear's are about rigidity, so Orbit should add flexibility as opt-in configuration on top of strong defaults.

## The sprint core is commoditised, and Orbit already has it

On sprint mechanics, the field has converged. Linear's cycles schedule automatically from 1 to 8 weeks, roll unfinished issues forward, and show a capacity dial based on the last three cycles' velocity ([Linear docs: Cycles](https://linear.app/docs/use-cycles)). ClickUp offers sprint dates, points, automatic roll-over, burndown and burnup, and velocity dashboards ([ClickUp Sprints](https://www.clickup.com/features/sprints)). monday dev bundles sprints, backlog refinement, burndown, velocity, retrospectives and AI daily standups ([monday dev](https://monday.com/dev)). Orbit's start/complete flow, move-incomplete step, points, burndown and velocity sit squarely in this band. The research found no source showing Linear has a Gantt view, native time tracking, a whiteboard or idea voting, though that is "not found" rather than confirmed absence.

The competitive differences sit in how vendors **gate** this core. ClickUp makes Sprint Points and Dashboards trial-only until its **Business tier at $17 per user per month** ([ClickUp pricing](https://clickup.com/pricing)). monday dev gates sprint management at Standard ($12 per seat) and imposes a **3-seat minimum with seat buckets** ([monday dev pricing](https://monday.com/dev/pricing)), so a solo user pays about $36 a month ([ClickUp's monday review](https://clickup.com/learn/topic/task-management/tools/monday/)). Core Asana only lets you "assign work to sprints" and shows no native burndown in the sources reviewed ([Asana features](https://asana.com/features)). GitHub Projects gained iteration fields and roadmaps but still has no built-in velocity or burndown charts in the sources found ([GitHub Docs: iteration fields](https://docs.github.com/en/issues/planning-and-tracking-with-projects/understanding-fields/about-iteration-fields)). The pitch "full scrum reporting on every plan, no seat minimum" is therefore real and defensible.

Orbit's bundle is its strongest cost argument against Atlassian. Jira Product Discovery, which covers ideas, insights, RICE-style formula scoring, matrix views and stakeholder roadmaps, is a separate product at **$10.50 to $26.25 per creator per month** ([JPD pricing](https://www.atlassian.com/software/jira/product-discovery/pricing)). Jira list prices rose about 7% in October 2026, reported as the sixth consecutive October increase ([PricingSaaS](https://pricingsaas.com/news/article/atlassian-raises-jira-cloud-prices-7-standard-climbs-to-8-48-per-user)). A Jira-equivalent stack means Jira plus JPD plus Confluence plus metered AI. Orbit already bundles ideas, whiteboards, time tracking and reports. Plane, the closest open-source rival, puts time tracking and work logs behind its Pro tier ([Plane pricing](https://plane.so/pricing)).

Orbit's ideas module covers voting, comments, dependencies, a mind map and convert-to-issue. It still trails JPD on customer insights attached to ideas, weighted scoring formulas, an impact-versus-effort matrix, idea-level fields, and delivery progress rolling back up to the idea ([JPD features](https://www.atlassian.com/software/jira/product-discovery/features)). Orbit already has public read-only links for flowcharts, and extending them to idea roadmaps would answer JPD's stakeholder sharing cheaply.

## Every rival now exposes an API, an MCP server and agent hooks, and Orbit exposes none

The sharpest gap is platform, not UI. Linear runs a read-write MCP endpoint plus a separate `/mcp/readonly` endpoint over Streamable HTTP. It authenticates with OAuth 2.1 and dynamic client registration, or with a bearer API key that can be restricted to read permission ([Linear MCP docs](https://linear.app/docs/mcp)). Atlassian's Rovo MCP server went GA on **February 4, 2026**, with clients including Claude, ChatGPT, Cursor and VS Code ([Atlassian blog](https://www.atlassian.com/blog/announcements/atlassian-rovo-mcp-ga)). It splits Jira tools into read, write, search, delete and manage permission groups, and the delete and manage groups are **disabled by default** ([Atlassian supported tools](https://support.atlassian.com/atlassian-rovo-mcp-server/docs/supported-tools/)). Asana (V2, OAuth) ([Asana dev docs](https://developers.asana.com/docs/using-asanas-mcp-server)), monday (hosted and open source, free on all plans) ([monday developer docs](https://developer.monday.com/api-reference/docs/monday-mcp-overview)), ClickUp (OAuth only, with daily call caps from 100 on Free to 25,000 on Enterprise) ([ClickUp pricing](https://clickup.com/pricing)), Plane (official, MIT-licensed) ([Plane MCP docs](https://developers.plane.so/dev-tools/mcp-server.md)) and YouTrack 2026.2 ([YouTrack What's New](https://www.jetbrains.com/youtrack/whatsnew/)) all ship MCP servers. An MCP server is now a baseline expectation, not a differentiator.

Beyond MCP, the market has moved to **agent delegation**. GitHub's Copilot cloud agent for Linear went GA on July 23, 2026: it runs in GitHub Actions, opens a draft PR and streams progress into the Linear timeline ([GitHub changelog](https://github.blog/changelog/2026-07-23-copilot-cloud-agent-for-linear-is-now-generally-available?from=bd_signal)). The Jira version entered preview in March 2026 ([GitHub changelog](https://github.blog/changelog/2026-03-05-github-copilot-coding-agent-for-jira-is-now-in-public-preview/)). Linear treats third-party agents such as Devin and Factory as assignable, non-billable workspace members driven by session webhooks ([Linear developers: Agents](https://linear.app/developers/agents)). Its own coding sessions write code with Claude Code and Codex in a cloud sandbox ([Linear changelog](https://linear.app/changelog/2026-06-11-coding-sessions)). Linear says triage agents resolve about **30% of its own incoming bug reports**, a vendor figure ([same](https://linear.app/changelog/2026-06-11-coding-sessions)). Asana launched a separate engineering product, Command, in September 2026 to turn decisions into tickets for coding agents ([Asana announcement](https://asana.com/inside-asana/command-by-asana)). Shortcut's Korey agent assigns work to "human or AI teammates" ([Shortcut Korey](https://www.shortcut.com/korey)). A tracker with no API or webhooks cannot be the place an agent picks up ORB-42 and reports back, and for developer teams that will soon look dated.

API norms are settled enough to copy. Linear allows **2,500 requests per hour for API keys and 5,000 for OAuth apps** ([Linear rate limiting](https://linear.app/developers/rate-limiting.md)). Its webhooks are signed with HMAC-SHA256 and carry delivery IDs and timestamps for replay protection ([Hookdeck guide](https://hookdeck.com/webhooks/platforms/guide-to-linear-webhooks-features-and-best-practices)). monday pins API versions with a date header ([monday dev docs](https://developer.monday.com/api-reference/docs/integrate-with-monday-mcp)). The MCP spec forbids token passthrough and requires per-client consent for proxy servers ([MCP security best practices](https://modelcontextprotocol.io/specification/latest/basic/security_best_practices)). Plane runs a local stdio MCP server with an API key for self-hosted users ([Plane dev docs](https://developers.plane.so/dev-tools/mcp-server)), which is a cheap first step for Orbit's desktop, local-first build before a hosted OAuth endpoint.

## AI pricing frustration leaves room for a bring-your-own-key copilot

The AI features users value cut admin work. Linear's Triage Intelligence suggests team, project, assignee and labels and surfaces semantically similar duplicates ([Linear docs: Triage Intelligence](https://linear.app/docs/triage-intelligence)). Atlassian promotes "instant context" summaries, one-click work breakdown, and a readiness checker that runs before planning ([Atlassian Jira AI](https://www.atlassian.com/software/jira/ai)). YouTrack turns a selected block of text into several new issues ([YouTrack AI assistant](https://www.jetbrains.com.cn/en-us/help/youtrack/cloud/ai-assistant.html)). monday dev generates sprint summaries and AI daily standups ([monday dev](https://monday.com/dev)). Orbit already holds the velocity, workload, burndown and activity data that capacity-aware sprint planning and automatic standup digests need.

Pricing is where incumbents are vulnerable. Atlassian pools Rovo credits at **25, 70 or 150 per user per month**, and overage billing at $0.01 per credit starts on **December 3, 2026**, on by default ([Rovo credits doc](https://support.atlassian.com/organization-administration/docs/usage-limits-in-atlassian-intelligence/)). Its automation is metered in steps at the same time, at $0.50 per 1,000 over allowance ([Automation usage doc](https://support.atlassian.com/cloud-automation/docs/how-is-my-usage-calculated/)). Reviewers call the credit pricing "hard to budget" ([eesel](https://www.eesel.ai/blog/atlassian-intelligence-and-rovo-pricing-explained)). Asana bills AI Teammates at $0.50 to $0.60 per request ([Asana pricing](https://asana.com/pricing)). ClickUp warns its AI prices "may be adjusted" if provider costs rise ([ClickUp pricing](https://clickup.com/pricing)). monday offers no bring-your-own key ([monday blog](https://monday.com/blog/ai-agents/everything-monday-ai-can-do/)). The only tracker examples of BYOK found were Plane's self-hosted AI (OpenAI, Anthropic, Bedrock or local Ollama, with Plane storing no keys or prompts) ([Plane blog](https://plane.so/blog/plane-ai-is-coming-to-self-hosted-deployments)) and Huly letting users pay compute through their own OpenAI account ([Huly pricing](https://huly.io/pricing)). The research found no BYOK in Linear, Jira, Asana, ClickUp or monday, though that absence is not proven.

Trust argues for drafts over auto-apply. In the Stack Overflow 2025 survey, **46% of developers distrust AI accuracy, up from 31%** ([Stack Overflow](https://stackoverflow.co/company/press/archive/stack-overflow-2025-developer-survey/)). Secondhand reports describe Rovo producing unreliable results, including an edit that erased a page ([beri.net](https://www.beri.net/tools/atlassian-rovo)). An Orbit copilot that proposes changes for a human to confirm, and pairs with a customer-visible agent activity log, answers both concerns. Few vendors document per-action MCP audit logs well; Atlassian tells customers to "monitor audit logs" but says little about their contents ([Atlassian supported tools](https://support.atlassian.com/atlassian-rovo-mcp-server/docs/supported-tools/)).

## Switching costs, not features, are Jira's moat, so importers come early

Complaint patterns are consistent and point at Orbit's opening. Capterra reviewers in 2026 describe Jira slowing on large boards, a steep learning curve, and the need for a dedicated admin for permissions and automation ([Capterra Jira](https://www.capterra.com/p/19319/JIRA/reviews/)). ClickUp reviewers report slow loading, bugs and notification noise ([G2 ClickUp](https://g2.com/products/clickup)). Asana's G2 negative tags cluster around "Learning Curve" and "Not Intuitive" ([checkthat.ai](https://checkthat.ai/brands/asana/reviews)). monday users are caught out by seat buckets ([Prospeo](https://prospeo.io/s/mondaycom-pricing-reviews-pros-and-cons)). Linear's complaints run the other way: it is opinionated and a reviewer says it "feels a bit like a cage" ([Subscribed.fyi](https://subscribed.fyi/linear/reviews/linear-review-6486)). Users also cite weak automation, complex epic management and reporting, and fear it "could become Jira one day" ([G2 Linear review](https://g2.com/products/linear/reviews/linear-review-9950469)). Shortcut's top complaint is reporting ([Capterra Shortcut](https://www.capterra.com/p/160498/Shortcut/reviews/)). The open position is "Linear-fast, but flexible where it matters," with configuration opt-in rather than mandatory.

Moving data is the barrier. One analysis argues switching cost, not quality, is Jira's moat ([Cotera](https://cotera.co/articles/jira-software-alternatives.md)). Linear treats importers for Jira, GitHub, Asana and Shortcut as basic infrastructure ([Linear docs: Import](https://linear.app/docs/import-issues)). Plane imports from Jira, Linear, Asana, ClickUp and CSV on its free tier ([Plane pricing](https://plane.so/pricing)). YouTrack 2026.2 added "continuous import" that keeps data in sync while a team migrates ([YouTrack What's New](https://www.jetbrains.com/youtrack/whatsnew/)). GitHub linking is the other switching blocker for developer teams. Linear's magic words move issues to In Progress when a PR opens and to Done on merge, with per-branch rules ([Linear docs: GitHub](https://linear.app/docs/github)). Orbit's existing GitHub sign-in makes this a natural extension.

Some table stakes remain thinly sourced in this research but show up across vendors. Custom fields appear at Plane, Shortcut, Taiga, Zoho and GitHub; GitHub's GA default set of **Priority, Effort, Start date and Target date** is a good minimum spec ([GitHub changelog](https://github.blog/changelog/2026-07-02-issue-fields-are-now-generally-available)). Configurable workflows, docs or wikis, WIP limits and intake forms are each found in several tools ([Plane pricing](https://plane.so/pricing); [Shortcut pricing](https://www.shortcut.com/pricing); [Zoho Sprints pricing](https://www.zoho.com/sprints/pricing.html)). The researchers could not verify from primary sources Jira's full set of custom workflows, typed links, releases, saved JQL filters, cumulative flow and control charts, and mobile apps, nor mentions and watchers across tools. Those items are widely assumed, and Orbit should treat them as expected regardless.

## Conclusion

The research changes the framing of Orbit's roadmap. Feature parity with Jira is the wrong goal, and competing on sprint UI is pointless because the core is already commoditised. The contest in 2026 is whether a tracker can serve as the system of record that agents, IDEs and chat tools read and write. Orbit's planned API keys and MCP server are therefore not "integrations work" but the foundation every later feature depends on, from GitHub linking to agent assignment to AI dedupe. Orbit should build them as REST plus OpenAPI with scoped keys mapped to its existing four-role RBAC, so the viewer role becomes a read-only scope with no new permissions model. BYOK is the one planned item that is also a genuine differentiator. Its timing is unusually good, because Atlassian's metered AI and automation overages switch on in December 2026.

The less obvious implication is sequencing against complexity. Each gap Orbit closes (custom fields, workflows, automations) moves it toward the complaints that drive people off Jira and ClickUp. A safer rule is "defaults first, configuration behind a toggle, and nothing metered." Three items in particular look cheap and distinctive: an agent activity log with undo, AI sprint and standup digests built from data Orbit already holds, and public share links extended to idea roadmaps. They play to Orbit's bundle rather than chasing breadth, and none of them is well served by the incumbents today.
